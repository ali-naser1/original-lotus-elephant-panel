# Design provenance

This lotus elephant panel is original procedural geometry created specifically for CNC metal cutting. It does not trace or incorporate external artwork.

The design is generated from geometric primitives and curves in `scripts/generate.py`: oval frame, frontal head, ears, eyes, tusks, trunk, lotus crown, and botanical side scrolls. The initially proposed horizontal base line was removed because every retained element connects naturally to the oval frame without it.
